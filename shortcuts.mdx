Also available in-app: the **?** panel in the bottom-left corner of the canvas.
Click it to expand or collapse; it remembers your choice.

## Playback

| Key | Action |
| --- | --- |
| <kbd>space</kbd> | Play / pause |
| <kbd>←</kbd> <kbd>→</kbd> | Step one frame |
| <kbd>Shift</kbd> + <kbd>←</kbd> <kbd>→</kbd> | Step one second |
| <kbd>Home</kbd> / <kbd>End</kbd> | Jump to start / end |
| <kbd>J</kbd> / <kbd>K</kbd> | Previous / next keyframe |

## Keyframes

| Key | Action |
| --- | --- |
| <kbd>⌘A</kbd> | Select every keyframe on every track |
| <kbd>Delete</kbd> | Delete selected keyframes |
| <kbd>Shift</kbd>-click | Add to selection |
| Double-click | Add or remove a keyframe |
| Right-click | Easing presets |

## Range

| Key | Action |
| --- | --- |
| <kbd>I</kbd> | Set the in point at the playhead |
| <kbd>O</kbd> | Set the out point at the playhead |

## Views

| Key | Action |
| --- | --- |
| <kbd>G</kbd> | Toggle the graph editor |
| <kbd>F</kbd> | Fit the timeline to the whole composition |
| <kbd>Alt</kbd> + scroll | Zoom the timeline |
| <kbd>Shift</kbd> + scroll | Pan the timeline |

## Dragging

| Key | Action |
| --- | --- |
| <kbd>Shift</kbd> + drag | Lock a graph-editor drag to one axis |

<Note>
  In Freeform mode only <kbd>space</kbd> is active — the rest operate on the
  timeline, which Freeform doesn't have.
</Note>
